## 本次发布

`dsh-yimu-bill` 正式发布到 npm；安装不再需要克隆仓库或本地编译。

### 重点

- `yimu-bill-cloud-mcp` 成为插件的 npm 依赖，`npm install dsh-yimu-bill` 会一并装好 MCP 与 SDK。
- 默认 MCP 入口改为解析 npm 依赖；从源码仓库开发时仍回退到相邻的 `../yimu-bill-cloud-mcp`。
- README 安装段改为：
  `dsh plugin --profile web add dsh-yimu-bill`，或 DSH 插件页安装；安装/升级后重启 DSH 即可。
- 功能与 0.2.0 一致：设置页扫码登录、记账模式、11 个业务工具；没有新增配置项。

### 升级

- 已安装 0.2.0 的用户执行 `dsh plugin --profile web add dsh-yimu-bill@latest`（或插件页升级），重启 DSH。
