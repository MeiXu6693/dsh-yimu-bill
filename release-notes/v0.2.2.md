## 本次发布

dsh-go 手机 App 新增原生「一木记账」面板，不需要 Web 设置页也能扫码登录。

### 重点

- 原生面板位于 **全部功能 → 一木记账**，以及对话详情 →「插件」页签。
- 面板直接显示二维码、登录状态，以及「刷新二维码 / 测试连接 / 退出登录」。
- **截图二维码**后到一木记账 App【首页】→【更多】→【扫一扫】扫码即可；dsh-go 原生协议不提供保存到相册的动作，因此不设保存按钮。
- 登录成功后照常写入 DSH 凭据，记账模式的 11 个工具立即可用。
- 不新增 TTL/超时/MCP 路径等设置项，全部使用默认值；DSH Web 设置页的扫码继续保留。
- 原生面板只在主机提供 `dshGo` 服务时注册；DSH Web/桌面端无副作用。

### 实现

- 新增 `lib/native.mjs` 与全局行 `yimu-bill-native`，复用现有 `createLoginController`。
- `lib/qr.mjs` 增加 PNG data URL（`qrcode`），供原生面板的 `image` 组件使用。
- `package.json` 增加 `dshGo` 面板清单与 `./native` export；`files` 仍覆盖 `lib/`。
