## 本次发布

登录从聊天工具搬到 GUI，并改为按「记账模式」加载记账工具。

### 重点

- 设置页新增「一木记账」：状态、扫码登录、退出、测试连接全部在页面内完成。
- 新增 **记账模式**：标准模式的完整能力 + 一木记账工具，按任务（会话）作用域生效；标准模式等其他模式看不到这些工具。
- MCP 兼容层：插件私有托管 `yimu-bill-cloud-mcp`，不再依赖 `mcpManager` / `dsh-mcp-client`。
- 移除 `yimu_login` / `yimu_login_wait` / `yimu_login_status` / `yimu_logout`（**breaking**）。
- token 存储位置、可读范围与注销限制写入 README（附 Playwright 实测：网页端退出不会让服务端 token 失效）。

### 内部

- 控制半拆分为 `lib/yimu-api.mjs`、`lib/login-controller.mjs`、`lib/qr.mjs`，官方接口只在一处维护。
- 删除终端二维码文本渲染，二维码 SVG 改为单 path；测试直接用矩阵解码。
- 插件版本改为从 `package.json` 读取；包内容增加白名单校验。
- `tools.mjs` 的 MCP 就绪等待计时器在完成后清理。

### 升级

- 按 README 以 profile bundle 安装/更新；安装或修改宿主代码后重启 DSH。
- 旧工具名 `mcp__yimu_cloud__*` 不再出现；记账工具在「记账模式」中以 `yimu_*` 出现。
